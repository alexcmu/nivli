# 15: 确认、纠正与遗忘个人记忆

**What to build:** 用户明确交代一个事实，能在“我的”查看、确认、纠正或遗忘它；推测保持待确认，“这次不要记住”不会变成长久记忆。

**Blocked by:** [07: 用 Pi 创建明确时间提醒](07-pi-create-reminder.md)

**Status:** ready-for-agent

**Parent:** [Nivli v1 Engineering Specification](../spec.md)

**规格定位：** US-40–US-43、US-56–US-57；D-02、D-04–D-05、D-07、D-10、D-12–D-13；AC-15–AC-16、AC-18。引用场景按本票范围验收，不要求提前实现其他票的功能。

**交付范围：** 自签名 v1 必需范围。 建立 Memory/Evidence 与有界检索、遗忘版本及最小抑制标记。这里只管理事实，关联产生行动建议由 16 实现。

**界面依据：** [Nivli UI 设计](../../../archived/nivli-ui-design.md)。使用原生 SwiftUI，沿用父规格的可访问性与错误反馈要求。

**测试边界：** 沿用父规格 T-01/T-02：从公开 API 验证外部可见行为，使用真实 PostgreSQL/pg-boss，仅替代模型、邮箱和推送等外部服务；涉及系统通知、权限或离线的结果补充原生真机证据。新增或修改的 API 同步维护 OpenAPI 与 Swift DTO 契约。

## Acceptance criteria

- [ ] 显式记忆指令或用户确认 proposal 才写 confirmed；inferred 单独显示待确认且默认不混入确认事实查询。
- [ ] Memory 保存 owner、事实值/类别、来源、有效时间、revision 和遗忘标记；新增/修改/删除均经公开 API，聊天和设置界面查看同一事实。
- [ ] 用户纠正事实产生新版本，失效/过期数据不进入确认检索；查询有范围和数量上限，中文查询包含验收样本，不要求向量数据库。
- [ ] “这次不要记住”禁止长期 memory 与相关派生摘要；界面说明原话仍可能在会话历史，提供后续删除对话的明确说明。
- [ ] 遗忘先令检索不可访问再清理派生数据；运行中的模型或工具根据版本拒绝回灌。旧聊天/来源不能自动重新提取，除非用户再次明确授权。
- [ ] 一次忽略、推迟或例外不生成长期偏好；无权限证据不能被模型引用，常规日志不含事实正文。
- [ ] 公开 API 测试覆盖显式记忆、inferred 确认、纠正、中文检索、遗忘和晚到 proposal；原生界面验证来源、两类状态与可理解的删除范围。

**完成条件：** 验收项全部通过并附可复核证据；需要外部凭据、真机或审核而尚未验证的项保持未完成。先满足所有 Blocked by，再开始实施；ready-for-agent 表示规格可实施，不表示依赖已经完成。

# 给 Haiji 开启远程通知：一步步操作

你只需要完成 Apple 网站里的账号操作，拿到两个编号和一个文件。服务器配置、App 构建和安装由我接着处理。现在不用运行终端命令，也不用理解队列、签名参数等术语。

整件事的顺序是：登录账号 → 给 Haiji 开启推送 → 下载推送密钥 → 我配置并安装 → 你在手机上测试。

## 当前进度（2026-10-15）

Apple 续费、App 推送能力、密钥下载和本机配置已完成，不需要重新做第 1–5 步。已在 USB iPhone 上验证 Apple 受理、通知中心展示及点开事项。云端没有配置或部署。

现在 App 只保留远程提醒。想测试通知，请按 [Portal 操作步骤](PORTAL.md)；测试通知不会添加假事项。

## 第 1 步：登录 Apple 开发者账号

1. 在 Mac 浏览器打开 <https://developer.apple.com/account/>。
2. 登录你用来给 iPhone 安装 App 的 Apple 账号；如果要求验证码，按提示验证。
3. 查看账号页有没有 **Certificates, Identifiers & Profiles**（证书、标识符与描述文件）入口。
4. 如果页面要求加入开发者计划、续费，或者没有这个入口，先停在这里，把页面上的提示告诉我。不要为了继续操作直接付款。

这一步完成的标志：能进入上面的证书管理页面。能免费安装开发版 App，不代表已经具备远程推送所需的账号能力。

## 第 2 步：给 Haiji 开启推送功能

1. 进入证书管理页面，点击左侧 **Identifiers**（标识符）。
2. 在列表中查找 `app.haiji.Haiji`。这是 Haiji 的唯一身份，请按这里的大小写填写。
3. 如果已经找到：点击这条记录，在功能列表里勾选 **Push Notifications**，然后保存。
4. 如果没有找到：点击左上角 **＋**，选择 **App IDs**，继续；如需选择类型，选择 App。
5. 名称或描述填写 `Haiji`。
6. Bundle ID 选择明确指定的类型（Explicit），填写 `app.haiji.Haiji`。
7. 在功能列表中勾选 Push Notifications，继续并确认注册。
8. 如果提示这个 ID 已被占用，先把提示告诉我，不要随便换一个 ID。

这一步完成的标志：列表中有 `app.haiji.Haiji`，并且它的推送功能已勾选。

如果看到“创建证书”，这次不用点。我们接下来使用密钥文件的方式。

## 第 3 步：创建并下载推送密钥

1. 仍在证书管理页面，点击左侧 **Keys**（密钥）。
2. 点击 **＋**。
3. 密钥名称填写 `Haiji Push Dev`。
4. 勾选 **Apple Push Notification service (APNs)**。
5. 如果旁边有 Configure（配置），点击它。第一次只做开发测试：环境选择 Sandbox（沙盒）；范围如可选，选择 Topic Specific，并选中 `app.haiji.Haiji`。
6. 如果没有这些选项，或者页面要求的内容不同，先把当前选项告诉我；不需要猜。
7. 检查信息并确认创建。
8. 在详情页找到 **Key ID**，把这个编号记下来。
9. 点击 Download（下载），保存下载的 `.p8` 文件。文件名通常类似 `AuthKey_XXXXXXXXXX.p8`。
10. 保留这个文件，不要把文件内容复制到聊天。Apple 的私钥只能下载一次。

这一步完成的标志：你有一个 `.p8` 文件，以及它的 Key ID。

如果页面提示密钥数量达到上限，不要删除其他密钥，直接告诉我提示内容。

## 第 4 步：找到 Team ID

1. 回到 <https://developer.apple.com/account/>。
2. 找到 Membership details（会员详情）。
3. 找到其中的 **Team ID**，记下这个编号。如果没找到，就告诉我你当前看到哪些栏目。

Team ID 表示开发团队；Key ID 表示刚创建的密钥。两者是不同的编号。

## 第 5 步：把这三项告诉我，后面的配置我来做

回复以下内容即可：

- Team ID：账号页面里看到的团队编号。
- Key ID：刚创建的密钥编号。
- 文件位置：例如“Mac 下载文件夹里的 AuthKey_XXXXXXXXXX.p8”。不用打开文件，也不用粘贴内容。

拿到这些后，我会检查密钥、配置后端，并构建与安装支持远程通知的 Haiji。如果当前服务器连接或手机签名还缺信息，我会在具体需要时再说明。

此步骤现已完成，私钥保存在本机私有目录，不进入代码仓库。

## 第 6 步：安装完成后，在手机上收一条测试通知

等我明确告诉你服务器和新版 App 已准备好，再操作这些步骤：

1. 用数据线连接并解锁 iPhone，配合完成安装。先保留原来的 App，不要自行删除。
2. 打开新版 Haiji；如果需要重新连接，使用我提供的服务地址和配对码。
3. 点击“我的 → 远程通知”。
4. 点击“启用或重新注册远程通知”。系统询问是否允许通知时，选择允许。
5. 新增一条手动事项，标题填写“远程推送测试”，时间选三分钟后。
6. 直接保存。所有提醒均走远程通知；若提示安静时段待确认，点击“仍在此时间提醒”。
7. 保持手机联网，回到主屏幕并锁屏，等通知出现。
8. 收到通知后，点击它，检查是否打开刚才的测试事项，并把结果告诉我。

如果没有收到，不要反复创建测试事项。告诉我事项页面显示的提醒状态，我来查原因。
